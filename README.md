## “静态”有三种写法，报价单上的那个可能不是你要的

行业里被标成“静态住宅”的东西，至少有三类。

**第一类，真家宽（ISP 代理）**：ASN 归属民用宽带运营商，IP 长期固定。这类最贵，养号和店铺长期登录选它。

**第二类，长效静态**：IP 确实固定，但线路落在机房或城域网，ASN 是 IDC 或云厂商。它的“静态”是真的，“住宅”是缺的，实测会被判成 hosting。不少平台把这类直接标成“静态住宅”。

**第三类，“静态”只是会话保持**：底层还是动态池，粘住一段时间后换 IP。做采集够用，用来养号会出事——账号登到第三周突然换了城市，风控当场标记。

分清的办法不是看商品名，是问三个问题：

1. 这条 IP 的 ASN 是 ISP 还是 IDC？
2. 租期内 IP 会不会变，变了算不算违约？
3. 是独享还是共享，同一 IP 同时段有没有别的用户？

WePC 页面写的“静态家宽 IPv4 ×1”对应第一类的描述，但商家标注不能替代实测。英国线路就有一个现成的例子：2026 年 3 月一篇第三方测评对 WePC 英国原生家宽做了 IP 属性检测，结论是原生英国 IP、商业属性、IP 库里没有标成 residential，但英国区 TikTok、ChatGPT、Claude、Netflix、Disney+ 都能正常解锁，Gemini 不行。

这条记录有两个用处。一是说明“商品名写家宽”和“IP 库判定为住宅”确实是两件事，必须自己查。二是说明平台风控并不只看 IP 库标签，实际能不能用，要拿你要跑的那个业务去试。那篇测评同时提到该机器的性能偏弱、延迟偏高、部分路由绕美，建议加中转，这属于第三方实测，只对应它测的那一档。

## 付款后头三天：四步验真，阈值写在这

WePC 的退款窗口和流量挂钩：开通 3 天内、流量使用不超过 10GB 才能退。所以验真必须压缩在头三天做完，而且别急着跑大流量任务。四步走完不到 10 分钟，但要在机器上执行。

**第 1 步，查 ASN 归属，一票否决。** 在机器上执行 `curl ipinfo.io`，或把分到的 IP 丢进 `ipinfo.io/<IP>`、`bgp.he.net`，看 ASN 的 owner。AT&T、Comcast、Verizon、中国电信、中国联通、中国移动这类是民用宽带运营商；Amazon、Google Cloud、DigitalOcean、阿里云、腾讯云、Vultr 是云厂商；名字里带 IDC、Hosting、Data Center 的是机房。小型区域 ISP 但 IP 段标注 hosting 的，进第 2 步复核。

**第 2 步，过三个 IP 类型库。** 同一个 IP 分别查 `ipapi.is` 或 `ip-api.com`（看 type：residential / hosting / proxy）、`IP2Location`（看 usage type：ISP / DCH / SES）、`Scamalytics`（看 fraud score）。判定标准是三个库里至少两个标为 residential 或 ISP，且 fraud score 低于 25。有一个库标 hosting，说明这个 IP 段被它收录为机房，用在该库下游的风控系统里照样会被识别。

**第 3 步，查黑名单和滥用记录。** `AbuseIPDB` 看举报次数和最近举报时间，再查 Spamhaus ZEN、SpamCop 这类主流 DNSBL。标准是近 90 天无举报、主流黑名单零命中。IP 出身真不等于 IP 干净，上一个用户拿它刷过单，你接手就是个脏 IP。这也是下单前值得问客服的一句：能不能指定没被用过的 IP。

**第 4 步，查 DNS、WebRTC 和时区。** 浏览器打开 `browserleaks.com/webrtc` 和 `ipleak.net`，看有没有泄漏真实出口、DNS 解析走本地还是走代理端、时区和语言跟 IP 所在地是否一致。很多“IP 对了但账号还是被封”的情况，根因是时区语言没跟着改，风控看的是整组信号自不自洽。

四步全过，这条 IP 可以用于养号；缺任意一条，只适合采集。这套流程和你要买的是哪家无关，换任何平台都适用。

## 六个容易踩的坑，每一个都能在下单前问清

**“独享 IP”被换成“独享线路”。** 独享 IP 指这条 IP 只给你用；独享线路只说明带宽不与他人分享，IP 可能还在共享段上。共享 IP 上有人违规，你的账号跟着连带。问法很直接：同一 IP 同时段有没有其他用户？

**流量单向还是双向。** WePC 美国档标的是 1.5TB 双向、澳洲档 2TB 双向，上传也算在额度里。做直播推流、云手机、多开的，上传量往往比下载大，双向计费下 1.5TB 的实际可用额度会比直觉少一截。

**超流量之后是限速还是停机。** WePC 美国 5 档写明限速 3M。3Mbps 意味着网页能开、视频推流基本废掉。做直播的要把这条算进成本：流量不够时是加钱买量，还是换更高档。

**退款窗口比想象中短。** 官网条款是开通 3 天内且流量不超过 10GB 可退：退到账户余额全额，但余额不能提现；退回原支付方式或指定账户，每台扣 10 元人民币手续费；用余额支付的订单只能退回余额。第 3 到第 10 天，不能再退回原支付方式，剩余部分退到余额并按已使用天数每天扣 6%。超过 10 天不退。同一笔交易不能退两次，每天最多 3 次、每月最多 5 次，账户充值本身不退，折扣套餐常被排除在外。结账页显示的条款才是最终有效的，下单前扫一眼。

**出口地区和宣称地区不符。** 低价海外档尤其常见。测法是买 3–5 条不同节点逐条查归属地，第一条不符就要求换。

**只改 IP，不改时区和语言。** 这一条和 IP 质量无关，但造成的封号最多。系统时区、浏览器语言、DNS 出口、WebRTC，四项里漏一项，前面的钱就白花了。

还有一句得说在前面：真家宽也不保证纯净度。同一 IP 段上用户行为累积会带来风险标记，这是所有真实住宅 IP 都绕不开的问题，没有哪家能承诺永远干净。静态住宅的“静态”指地址不变，不指永不被封。
